# gzlite 0.14.0 toolchain refresh

Checked November 28, 2026. The rollback reference is Task 14 merge
`3ca3f96aaee59c16fec5b9506a183618887d977e`. The release advances the
published 0.13.0 baseline to 0.14.0. These changes refresh verified
selections within the existing supported Python and uv ranges.

Queried both complete locked environments with uv against PyPI. Both locks
were resolved with uv 0.13.10. The build backend, reference examples, hosted
checks and packaged adopter workflow were reconciled. The uv executable
floor remains 0.13.5.

Retain [CPython 3.14.10 and 3.12.16](https://www.python.org/doc/versions/)
under the N-1 and [XPPython3 host](https://xppython3.readthedocs.io/en/latest/usage/installation_plugin.html)
rules. The standalone X-Plane reference covers its managed Python. Embedded
XPPython3 runtime behavior remains unverified.

Official release metadata confirms checkout v7.0.1, setup-uv v10.4.0, SP
v7.0.2, gz-skills v0.14.0 and Backplane v0.3.0. Backplane remains disabled.
The Python 3.14 opportunity review selected no new API for this refresh.
The release guard uses Git, existing pathlib operations and standard-library
JSON/TOML parsing without changing interpreter requirements.
