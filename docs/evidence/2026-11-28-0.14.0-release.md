# GZ Lite 0.14.0 release candidate

The maintainer authorized the 0.14.0 release and the GitHub repository rename
once the candidate passes. The published baseline is 0.13.0 at
`98acc5aeec3f3b6ad61171a647dbc0ab7a44b7c6`. The
[approved minor scope](../../ROADMAP.md#selected-0140-minor-scope--gzlite-rename-and-tool-move-november-27-2026)
covers the rename, adopter migration, tool split and release safeguards.
The [adopter bridge](../migrating-from-gz-starter.md) requires review of
each migration and freshen fingerprint.

## Candidate checks

- Both Python baselines were checked against live official releases and
  updated in the [toolchain receipt](2026-11-28-0.14.0-toolchain.md).
  The locked audit found no known vulnerabilities in either export.
- The Windows gate and installed distribution checks use managed Python
  3.14.10 and uv 0.13.10. The installed entry points exercise profile
  inspection, portability, catalog checks, an untagged-ref refusal and a
  fingerprint-reviewed legacy migration followed by a freshen preview.
  The standalone X-Plane baseline passed on managed 3.12.16.
- The history builder preserved the real 22 legacy releases and rejected an
  invented dated release lacking a tag. The release guard rejects incorrect
  mirrors, lightweight tags, wrong tag and GitHub target commits and a
  metadata bump made before the dated release entry.
- The independent whole-branch review identified public updater instructions,
  managed junctions, missing preservation of edited marketplace pins,
  changes during preview, uv archive checksums and vendor rollback. The
  corrected candidate covers the junction, pin and rollback regressions with
  failing then passing tests. Both downloaded uv archives matched the
  packaged verification workflow's SHA-256 values.
- Ruff C901 and the Lizard function and aggregate checks passed. Vulture at
  confidence 90, deptry and Import Linter reported no findings. Cosmic Ray
  8.9.0 passed the bounded unittest compatibility controls with two mutations
  killed and two surviving. Bandit's YAML diagnostic uses a SafeLoader
  subclass with tests for unsafe inputs. Interrogate reports docstring gaps
  below its 80% default threshold, which remains visible for follow-up.

## Boundaries

- Acceptance is conditional under the
  [cognitive deferral](../engineering/cognitive-integration.md#starter-wide-qualification-deferral).
  The ceiling remains 15 and the measurement is UNKNOWN. Backplane is disabled.
- Fresh native discovery, the hosted adopter workflow on macOS ARM64 and
  Windows x64, and the embedded XPPython3 runtime remain unverified for this
  candidate. An installed command and verified archive digest do not prove
  native discovery or deployment.
- The [release safeguards](../engineering/release-guards.md) describe the
  live GitHub settings. Activation requires its own authorization.
- Native development settings keep a previously published catalog SHA
  to avoid a self-reference. Other work, including the gz-skills v0.15.0
  follow-up for gzlite 0.14.1, remains in the roadmap.

The published GitHub release names the full tagged commit. Verify the exact
candidate, main merge and published release through the [release safeguards](../engineering/release-guards.md).
