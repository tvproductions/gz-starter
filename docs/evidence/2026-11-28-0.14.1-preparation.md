# GZ Lite 0.14.1 preparation

Checked November 28, 2026, on Windows. Published GZ Lite v0.14.0 at
`5cfbf9552cb6b4d1e63b582b90b3d4a9d92342b0` is the baseline. The pending
0.14.1 patch follows [Task 13](../superpowers/plans/2026-11-27-gzlite-0.14.0.md#task-13-gzlite-0141-after-gz-skills-v0150-is-released).
The preparation started from `f8f9b8fcbb0c036bbaacd104849996ea0c0d805b`
on `main`. GitHub identifies the published baseline by the same peeled tag
and release target. Its [candidate](https://github.com/tvproductions/gzlite/actions/runs/46154876510)
and [merge](https://github.com/tvproductions/gzlite/actions/runs/46155057625)
passed all three CI jobs on their respective SHAs.

  selections. Refer to the [0.14.0 inventory](2026-11-28-0.14.0-toolchain.md)

  carry forward.
- The [Python 3.14 pathlib documentation](https://docs.python.org/3.14/library/pathlib.html#pathlib.Path.walk)
  informed the Markdown scan. The scan uses top-down directory pruning, avoids
  following links and reports enumeration errors. It reuses the current
  reader, path policy and fingerprint. This change needs no additional
  dependency, concurrency, file-copy or annotation API.

## Implementation evidence

- Public CLI tests failed before the pin, rename reporting and snapshot changes
  and passed afterward. They cover byte preservation, stale-fingerprint
  refusal and updating an untouched 0.14.0 fragment with all three current
  skill names. The generated history retains the 22 legacy tags and includes
  the exact published 0.14.0 snapshot.
- Independent review found that a same-version development bundle could claim
  the old release SHA, and that a legacy lock could name a modern snapshot.
  Both defects were reproduced and corrected, along with the Markdown
  enumeration diagnostic. A preview against the real 0.14.0 tag refused the
  different running bundle and left the temporary adopter empty.
- The standalone X-Plane baseline passed with uv 0.13.10 and managed
  Python 3.12.16. Ruff C901 passed for `src` and the history generator.
- The standard Windows suite ran 378 tests with six platform skips on
  managed Python 3.14.10 and uv 0.13.10. The four-hook gate also ran in a
  disposable checkout with 0.14.1 package, bundle, lock and catalog names.
  Both catalogs validated there. The 0.14.1 sdist and wheel built and passed
  the installed CLI and packaged-resource checks.

## Release boundaries

The preparation keeps `bundle.json`, `pyproject.toml`, `uv.lock` and the catalog
names at the published version on `main`. The 0.14.1 release commit must first
set the version mirrors and date the changelog entry.

gz-skills maintenance workflow. Official sources and the repository inventory
