# GZ Starter 0.12.0 release

The maintainer authorized publication of **0.12.0**. Published baseline
**0.11.6** at `6a44715f5fc40048c9767497a313a279dfc3a12a` advances to
**0.12.0 / minor**. The starting `main` and `origin/main` matched at
`5e0136139ac02977d4f9493c088b32c2b721e3b2`. The
[selected work](../../ROADMAP.md#selected-correction--pre-implementation-verification-november-17-2026)
adds a supported verification command, development extra and adopter workflow.
The [adopter migration](../adoption-workflow.md#configure-the-adopter-verifier)
explains the opt-in installation and replacement of the old unittest hook.

## Candidate scope and freshness

The [release inventory](2026-11-21-0.12.0-dependencies.json) records official
sources for both Python baselines. It identifies the `virtualenv` release-time
patch from 21.15.11 to 21.15.12 in both locks. Python families and component
selections are retained. The verifier extra explicitly declares the existing
PyYAML 6.0.4 package. The pinned macOS/Windows uv archives, pre-commit entry and
routine Ruff check, Ruff format, ty and unittest categories remain in force.

The [candidate acceptance receipt](2026-11-21-0.12.0-candidate-acceptance.md)
records the earlier producer and installed-artifact findings, the Windows
and macOS controls and the scoped on-demand evidence. The release keeps the
same verifier source and workflow recipe. The final release checks exercise
the changed locks and the installed extra. Hosted negative controls run
inside one private manual workflow that checks the expected raw statuses and
diagnostics within green jobs.

## Exact-release acceptance

- With the final locks, uv 0.13.9 and managed CPython 3.14.10 passed the four
  local hooks, bundle and catalog validation, packaged resource parity, the
  source-independent build, and isolated installed-distribution checks.
  Unittest ran 128 tests with one Windows junction case skipped on macOS.
  The standalone X-Plane check passed on managed CPython 3.12.16.
- Both jobs in [exact-commit producer CI](https://github.com/tvproductions/gz-starter/actions/runs/44958719681)
  passed for `7303deff043231d8bcbb789e52efdbdde6b7e2f0`.
- Private manual run `44958752933` used fixture commit
  `7052f358e6e93309afcdff10f9e69ae725177271` and installed the verification
  extra from that full starter release SHA. macOS ARM64 and Windows x64 each
  passed eight assertions with uv 0.13.9 and managed CPython 3.14.10. The run
  checked authenticated exact-SHA checkout, bootstrap, the first authored
  source without tests, a reached assertion failure, a successful suite, an
  omitted module, a skipped-only suite and the independent coverage threshold.
  The unchanged hook was exercised in every adopter case. The shared fixture
  lock SHA-256 is
  `24d4d50833b04f330f93053c230d969fb41fef2355c765ee021f7a775623486e`.

## Retained limits

Release acceptance is conditional under the
[standing cognitive deferral](../engineering/cognitive-integration.md#starter-wide-qualification-deferral).
Cognitive measurement remains **DEFERRED / UNKNOWN**, ceiling 15. The
standalone X-Plane reference is separate from embedded XPPython3 execution,
which remains unverified. Backplane remains disabled and its host readiness
open. The installed verifier does not qualify native plugin discovery or
adopter domain behavior beyond the recorded controls.
