# GZ Starter 0.12.0 candidate acceptance

The maintainer authorized main synchronization and an invented private adopter
fixture. Published **0.11.6** advances to pending **0.12.0 / minor** under the
[bootstrap verification scope](../../ROADMAP.md#selected-correction--pre-implementation-verification-november-17-2026).
The tested candidate is `0550d84eac172a81ea3b8395379ddaa360bd8348`.
Release acceptance is **conditional under the existing cognitive deferral**.
The release remains unpublished.

## Producer and dependency evidence

- Normal commit hooks passed. On macOS, uv 0.13.9 and managed CPython 3.14.10
  passed the four-hook gate, catalog validation, resource parity, source-independent
  build and the isolated installed wheel check with a cold cache.
- Both jobs passed in the [exact-candidate CI run](https://github.com/tvproductions/gz-starter/actions/runs/44951445071).
  Linux executed the producer gate, build and installed artifact checks. The
  separate X-Plane reference passed on managed CPython 3.12.16. Embedded
  XPPython3 execution remains unverified.
- The [candidate dependency inventory](2026-11-21-0.12.0-candidate-dependencies.json)
  covers 76 PyPI projects, both Python families and the selected tool and
  component releases. Both hashed lock audits checked 75 packages with zero
  known advisories or skips. The follow-up changes only test setup and handoff
  prose, so the hashed inventory inputs match the accepted candidate.

The initial [producer run](https://github.com/tvproductions/gz-starter/actions/runs/44950848674)
failed in two fixture lock-generation steps because a fresh runner cache
lacked registry index metadata. A local cold-cache replay reached the same
failure. The follow-up resolves the explicitly pinned fixture dependencies
when generating their locks. Execution uses those locks. The runtime verifier
and workflow recipe are byte-identical between the two candidates. The private
adopter was re-pinned and all cases were repeated on the follow-up SHA.

## On-demand evidence and limits

- Scoped Ruff C901, Lizard, deptry and Import Linter passed. Lizard measured
  71 functions with maximum 19 and no violations. The CLI wrapper import
  contract and separately owned workspace/adopter gates remain in effect.
- Interrogate measured 38 of 82 docstrings in the selected implementation and
  distribution-check scope (46.3%). Its tool-default 80% comparison returned
  nonzero. Project policy requires measurement and review. Vulture reported
  only three parameters in an unchanged ADR test. Bandit reported no high
  findings. Its YAML loader finding was reviewed against the custom `SafeLoader`
  and reached malformed/tag/alias controls. The low findings cover fixed
  executable argv, subprocess imports and the boolean `pass_filenames` field.
- Focused unittest coverage measured 333 of 662 statements and 92 of 310
  branches across the instrumented verifier files. Nested target interpreters
  have incomplete instrumentation. The actual installed fixture independently
  proves the nested runner's selected behaviors on both hosted platforms.
- Cosmic Ray 8.9.0 reported `normal/survived` on the unchanged baseline and
  `normal/killed` when the no-success guard was inverted in a disposable copy.
  Direct replay reached the changed exit-status assertions. The original
  runner bytes were restored and verified.
- Cognitive ceiling 15 remains **DEFERRED / measurement UNKNOWN** under the
  [starter-wide deferral](../engineering/cognitive-integration.md#starter-wide-qualification-deferral).
  Cohesion remains adopter-owned. The qualification concerns the installed
  verification command and checkout workflow. Embedded host and Backplane
  readiness retain their existing limits.
