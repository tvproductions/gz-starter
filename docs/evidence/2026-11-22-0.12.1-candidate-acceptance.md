# GZ Starter 0.12.1 candidate acceptance

Published baseline **0.12.0** at `7303deff043231d8bcbb789e52efdbdde6b7e2f0`
advances to **0.12.1 / patch** for the [selected state-directory correction](../../ROADMAP.md).
The candidate writes starter state to `.gz-starter/` and requires a reviewed
reconciliation when it recognizes legacy state. The [adopter procedure](../updating.md#relocate-legacy-starter-state)
covers relocation, a full upgrade, and rollback.

## November 22 local evidence

- Managed CPython 3.14.10 and uv 0.13.9 exercised the four routine hooks,
  bundle and catalog checks, resource parity, a source-independent build,
  and installed wheel verification. Unittest ran 135 tests with one
  Windows-only skip. The standalone X-Plane reference passed
  on managed CPython 3.12.16. Embedded host execution remains unverified.
- Independent review found effective permission handling, state introduced
  during apply, and instructions that read a lock before checking its path.
  Added reached-failure regressions for the first two findings, applied the
  fixes, and updated the instructions to inspect metadata before opening a lock.
- A disposable macOS ARM64 rehearsal used the released 0.12.0 helper to create
  legacy state. A local candidate install refused legacy and linked state,
  distinguished a relocation with preserved provenance and local policy edits
  from a reconciled candidate, and exercised the unchanged unittest hook.
  This used local source and does not establish exact-commit hosted acceptance.
- Changed-source Ruff C901 and the import boundary passed. Lizard measured
  maximum complexity 19 against ceiling 20. Deptry reported no missing or
  unused dependencies. Interrogate reported 74.6% in the measured scope,
  below its default 80% comparison. Vulture flagged the existing YAML loader
  dispatch method and unused parameters in an existing ADR test. Bandit found
  no high-severity findings. Its YAML loader and fixed-argv findings are the
  same unchanged surfaces reviewed for [0.12.0](2026-11-21-0.12.0-candidate-acceptance.md).
  Coverage with branch measurement reported 87% on `paths.py` and 86% on
  `cli.py`. The parent collector does not measure child interpreter
  coverage. Cosmic Ray's disposable compatibility probes observed both killed
  and survived mutations.

## Initial candidate freshness

The official release checks confirmed uv 0.13.9, checkout 7.0.1, setup-uv
10.4.0, Superpowers 7.0.2, gz-skills 0.14.0, and deferred Backplane 0.3.0.
Hash-pinned registry audits reported no known vulnerabilities in either
of the current locks.
Read-only upgrade resolution identified [filelock 4.3.0](https://pypi.org/project/filelock/4.3.0/)
in place of 4.2.12 for both baselines. The [November 21 maintenance receipt](2026-11-21-post-release-maintenance.md)
describes the earlier inputs. Dependency maintenance is outside the selected
state-directory patch. The refresh was awaiting separate authorization at
that checkpoint.

## Release candidate refresh

The maintainer reaffirmed publication authorization and separately approved
the dependency refresh on November 22. Full upgrade resolution updated only
filelock from 4.2.12 to [4.3.0](https://pypi.org/project/filelock/4.3.0/) in
both locks. PyPI lists non-yanked artifacts and Python >=3.11. The official
runtime and release checks retain Python 3.14.10 and 3.12.16, uv and uv_build
0.13.9, checkout 7.0.1, setup-uv 10.4.0, Superpowers 7.0.2, gz-skills 0.14.0
and disabled Backplane 0.3.0. The earlier local behavior results above were
recorded before this lock refresh.

- The resolved lock SHA-256 values are
  `586d318526d2a7db37a9e0a8230bfa7c22dd7acade1d9ce42dd324edf922e459`
  for the standard baseline and
  `4ab6dbf55776cc8bccf66b0e0e0e788998cf085570a398a30748b133e3161da1`
  for X-Plane. Both hash-pinned registry audits checked 75 packages and
  found zero known vulnerabilities and zero skips.
- After the refresh, all four routine hooks passed with 135 unittest tests
  and one Windows-only skip. Catalog and resource checks, the
  source-independent build, isolated installed CLI checks, version output
  and the standalone X-Plane checks passed.

The release requires producer CI and the private macOS ARM64 and Windows x64
controls against the final source. Cognitive measurement stays
**DEFERRED / UNKNOWN**. Embedded XPPython3 execution remains unverified and
Backplane readiness remains deferred.
